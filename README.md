# Muhammed Dakarli — Portfolio

Arabic, RTL portfolio for website design, web development and Android/Flutter services. Static HTML, CSS and JavaScript, with no build dependencies or required secrets.

## Local preview

```sh
python3 -m http.server 8080
```

Open http://localhost:8080. All source content is in `index.html`; styles in `style.css`; mobile navigation and project filters in `script.js`.

## Vercel

Import `muhammed050/muhammeddakarli` into Vercel. Choose **Other**, root `.`, leave the build command empty and output directory `.`. The included `vercel.json` provides the static configuration. No environment variables are required.
